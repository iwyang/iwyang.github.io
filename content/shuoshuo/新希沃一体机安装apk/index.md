+ **新希沃一体机进入调试菜单安装apk：**

关机长按电源键30秒直到电源键红白闪烁松手，进入诊断三图标画面 → 快速敲击屏幕右下角空白处5下（位置不对没反应的） → 点击输入框 → 输入1379 → 进入调试菜单

操作指导视频：https://drive.cvte.com/p/DYnztycQnJ4EGOfNGQ

+ **新希沃还原系统**

设备先关机 → 关机状态（指示灯为红灯状态） → 长按电源键30秒大约（设备会开机，不要松手，待指示灯红蓝闪烁时松手） → 进入诊断三图标画面 → 系统恢复 ，pc恢复
长按电源键还原系统：https://drive.cvte.com/p/DVezmrcQ2f8EGPv8JyAA

PS：还原系统可能会存在小概率的风险，可能会导致C盘格式化或部分文件丢失，也有可能会导致系统无法进入，所以您需谨慎还原，还原前最好先备份好C盘及桌面的重要文件。还原重装后设备如提示激活Windows系统需联系设备提供方/经销商咨询确认处理。若设备上有认系统的软件在重装系统后也有导致丢失原激活版的使用功能希沃无法为您恢复原状态，请您留意慎重考虑。
